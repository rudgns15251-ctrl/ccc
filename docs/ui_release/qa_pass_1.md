# UI/UX QA 1차 — 직접 플레이 점검 (2026-10-16)

> 대상: T04 출시 프리뷰(F6, FACILITY CONTROL + 출시 Theme), 1280×720 기본 창.
> 방법: T04 세 경로(C 성공 / A 비탈출 실패 / B 탈출 → 방송 → 보고서 → 복귀)를 GPU 창에서 끝까지 플레이해 화면 36장을 캡처했습니다. 연구 기록, 메모, 실험 상태, 승인 확인창 같은 보조 화면도 포함합니다. 각 화면을 비교작(Papers, Please, Not For Broadcast, I'm on Observation Duty, Home Safety Hotline)의 정보 전달 원리와 대조했습니다.
> 한계: 스크립트로 조작한 플레이입니다. 사람의 손으로 느끼는 반응 속도, 소리 체감, 재미는 평가하지 못했습니다.
> 캡처: [screenshots/ui_release_theme/qa1](../screenshots/ui_release_theme/qa1)(`before_*` / `after_*`).

## 유료 에셋이 없어서 부족해 보이는가?

**일부는 맞고, 대부분은 아닙니다.**

- **에셋이 필요한 부분**(구매나 제작 없이는 해결 불가):
  - 실제 CCTV, 실험, 사고 이미지(지금은 합성 1종).
  - 마모와 각인이 있는 장비 재질 텍스처(지금은 코드로 만든 노이즈).
  - 타이틀 아트와 로고.
  - 종이 넘김, 도장, 무전, 경보 같은 소리.
  
  이 부분은 "장소감"과 첫인상을 좌우합니다.
- **에셋과 무관한 부분**(이번 QA에서 찾은 문제 대부분):
  - 같은 정보의 중복 표시, 빈 자리표시, 좁은 대화창, 잘못된 색 사용, 공간 배분, 회귀 버그.
  
  출시작과의 이질감은 오히려 이쪽에서 더 크게 생깁니다. 그래서 이번에는 이 부분을 먼저 고쳤습니다.

## 아직 출시작과 차이가 큰 부분 (다음 후보)

1. **지연 결과 읽기 패널**(11번): 격리 판정을 "사건"처럼 전달하는 것이 핵심 경험인데, 지금은 상태줄 한 줄입니다. 에셋 불필요.
2. **방송 화면 레이아웃**(10번): 상황 패널과 선택지의 비율을 조정합니다. 에셋 불필요.
3. **화면 장소감**: 콘솔 프레임, 실제 재질, 이미지. **에셋 필요**(구매, 외주, 직접 제작 중 결정).
4. **소리 보강**: 종이, 도장, 무전, 경보. CC0(BigSoundBank)로 일부 해결 가능하고, 고품질은 Sonniss 같은 구매가 필요합니다.
5. **정식 콘텐츠**: Profile 영어 항목명과 [TEMP] 줄은 정식 Case를 작성할 때 정리합니다.

## 검증
- 세 경로를 1280에서, 탈출 경로를 1920에서 실행: 실패는 옛 기대값 `honest_cctv` 1건뿐(M5-B.1에서 의도적으로 바뀜).
- 메뉴 흐름 14항목 PASS. verify PASS(79 scripts). Scene 5개 시작 exit 0.
- 사용자 데이터: 이번 QA의 전체 경로 실행(`--mode=all`)이 성공 경로에서 T04 테스트 저장을 실제 사용자 폴더에 남겼습니다. 모두 삭제했고, 기존 M2 저장 해시가 그대로임을 확인했습니다.
  - **다음부터 이 모드를 쓸 때는 실행 후 T04 저장 정리가 필요합니다.**

## QA 2차 (같은 날) — 지연 결과 패널 + 방송 화면

**수정**
- **지연 결과 읽기 패널**(11번 해결): ROOM A/C 결과가 처음 공개되는 순간(후속 업무 CCTV) 종이 보고서 패널로 전달됩니다.
  - 판정 제목과 도장: 안정은 녹색 잉크, 부적합은 적색 잉크이고, 비탈출 실패에는 "탈출 없음"을 표기합니다.
  - 승인한 격리실 이름, 기존 Research 본문(새 문구 없음)을 보여줍니다.
  - 버튼: [확인] / [기록 보관함에서 보기].
  - 불러오기 후 다시 공개되는 경우와 ROOM B(경고와 사건으로 따로 전달)에는 띄우지 않습니다. 열려 있는 동안 Esc와 일시정지는 패널 닫기를 우선합니다.
  - 파일: `scenes/release/result_notice.tscn`, `scripts/release/result_notice.gd`, `t04_playtest.gd`의 공개 지점, presenter.
- **방송 화면**(10번 해결): 상황 패널 폭 440→600. 단계 표시줄은 배너 상태 문구와 중복이라 숨겨 높이를 확보했습니다. 상황 패널의 [임시] 접두어도 정리했습니다(송출 원고 미리보기는 손대지 않음).
  - 결과: 상황 설명 전체와 질문 문장이 보이고, 선택지가 2개 이상 보입니다.

**QA 플레이 확인**
- 세 경로를 1280에서 다시 끝까지 플레이했습니다. A와 C에서 "보고서 표시 → 확인으로 닫힘" 검사를 추가했고 통과했습니다.
- 탈출 경로를 1920에서 실행했고, 메뉴 흐름 14항목 PASS. verify PASS(80 scripts). Scene 5개 시작 exit 0.
- 실패는 옛 기대값 `honest_cctv` 1건뿐입니다.
- 처음 캡처에서 보고서가 반투명해 보였는데, 페이드 중간에 찍힌 것이었습니다. 페이드가 끝난 뒤 다시 찍어 정상 표시를 확인했습니다.
- 사용자 폴더의 T04 테스트 저장은 정리했고, M2 저장 해시는 그대로입니다.
- 캡처: [screenshots/ui_release_theme/qa2](../screenshots/ui_release_theme/qa2).
