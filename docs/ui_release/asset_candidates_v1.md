- 현재 사용 중: 무료 샘플 3개(CC BY 4.0)가 `assets/third_party/m4_5/analog_horror_sfx_free/`에 있다.
- 적합도: **높음.** 계획된 장면과 직접 맞는다. 프롤로그의 비디오테이프(삽입·재생 소리와 기존 영상 전환), 챕터1 종료의 환풍구 긁는 소리, 강제 방송 이벤트의 사이렌·정전·사이렌 정지의 정적, 메뉴의 "증거 발견".
- 라이선스(페이지 기준): 상업·비상업 게임에 무제한 사용, 출처 표기 불필요, **소리 자체의 재판매·재배포 금지**. 전문은 구매 후 파일에서 확인해야 한다(미확인).
- **주의 1:** "소리 자체를 재배포하지 않는다"는 조건 때문에 **공개 GitHub 저장소에 원본·가공본 WAV를 커밋하면 안 된다.** `assets/local_only/`(Git 제외)에 두고, 게임 빌드(PCK)에만 포함한다. 현재 저장소는 `origin`이 `ccc.git`이며 공개 여부는 확인하지 못했다.
- **주의 2:** 페이지에 "AI assistance(소리는 코드로 합성)"라고 명시되어 있다. 판매 플랫폼의 AI 생성물 공개 규정을 출시 전에 확인해야 한다.
- 용량: 116MB(전체). 필요한 것만 골라 빌드에 포함하면 늘어나는 용량은 작다.

## 3. 구매 시 지켜야 할 규칙
1. **구매·가입은 사용자만 한다.** 저는 대신 결제하거나 계정을 만들지 않는다.
2. 구매 후 `.zip`을 `assets/local_only/paid/<이름>/`에 두고, **라이선스 파일 전문을 제게 보여 주면** 조건을 다시 확인한 뒤 사용 범위를 정한다.
3. 재배포 금지 조건이 있는 팩은 **공개 저장소에 커밋하지 않는다.** 필요한 파일의 목록과 출처만 `assets/third_party/PAID_MANIFEST.md`에 기록한다.
4. 게임 빌드에는 쓰는 파일만 넣는다. 크레딧에는 표기 의무가 없어도 출처를 적는 편을 권한다.
5. AI 보조로 만든 자산(VHS UI, SFX)은 판매 플랫폼의 공개 규정을 출시 전에 확인한다.
6. 구매 전 가격은 할인 중이므로 변동될 수 있다.

## 5. Dead Channel 무료 샘플 검증 결과 (2026-10-18, 사용자 승인 다운로드)
- **받은 파일:** `Dead-Channel-Free-Sample-v1.1.zip`, 186,686바이트(페이지 표기 182kB), itch.io 공식 다운로드 흐름(무료, 로그인 없음). SHA-256 `adf3b023c3a64a44d2394f8a7db52ec5a3d91a2e067b8368c9be5706b6dabb01`.
- **위치:** `assets/local_only/paid/dead_channel_free_sample/`(Git 제외, `assets/local_only/paid/.gdignore`로 메인 프로젝트 import 차단). 압축은 `extracted/`에 풀었고, 압축 안의 경로는 모두 단일 루트 폴더 아래였다. **게임에는 연결하지 않았다.**
- **라이선스 전문 요지(LICENSE.txt, SAMPLE-CODE-LICENSE.txt):**
  - 개인·상업 게임 등 완성작에 사용·수정 가능, 여러 프로젝트에 사용 가능, 표기 불필요, 로열티 없음.
  - 협업자에게 소스 파일 공유 가능(그 협업자는 무관한 프로젝트에 쓰면 안 됨).
  - 완성작의 일부로 배포 가능. **단독 에셋 모음·스톡·템플릿으로 재판매·업로드·재배포 금지. 원본 다운로드나 소스 에셋 모음을 "추출 가능하게 공개"하는 것도 금지.**
  - 샘플 아트워크·문서·코드는 **AI 보조로 제작**되었고 독점 소유권을 주장하지 않는다.
  - IBM Plex Mono는 별도 SIL OFL 1.1이며 OFL.txt와 저작권 고지를 함께 배포해야 한다.
  - 이 허가는 **샘플에만 해당한다.** 유료 풀 키트의 라이선스는 별도이며 아직 확인하지 못했다.
- **Godot 4.7.1 동작:**
  - 헤드리스 import 오류 없음, 120프레임 실행 오류·경고 없음, 스크립트 구문 검사 통과.
  - 창 모드(GL 호환)에서 확인: 기본 화면, 게인 슬라이더 85, 연결 해제, 리셋(게인 50 복귀, 상태 문구 복귀), 버튼 키보드 포커스 표시 모두 정상. 신호 파형이 게인과 연결 상태에 반응했다.
  - 이 확인은 4.7.1에서의 샘플 동작이다. 풀 키트의 데모와 테마 3종은 확인하지 못했다.
- **한글:** IBM Plex Mono에는 한글이 없다. 한글 문구는 시스템 대체 글꼴로 표시되어 보였다(테스트 문구 정상 표시). 시스템 대체 글꼴은 사용자 PC에 의존하므로 **게임에서는 동봉 한글 글꼴을 지정**해야 한다. 영문 모노 + 한글 고딕 혼합은 현재 화면 규칙과 같다.
- **시각 평가:** 청록색 단색 인광 모니터 스타일. 노치 모서리 윤곽선 버튼과 얇은 선의 패널. 파형 표시는 방송 송출이나 신호 수신 화면에 어울리지만, 질감 있는 강철 장비 패널(Instrument Steel)과는 시각 언어가 다르다. 전체 테마로 교체하기보다 "신호 표시 모듈"로만 쓰는 편이 안전하다.
- **샘플 코드 주의:** `Sample.gd`의 `open_full_pack()`은 `OS.shell_open`으로 외부 사이트를 연다. 어떤 형태로든 게임에 가져오지 않는다.
- **판단(갱신):** 풀 키트 $15는 **지금 구매하지 않는다.** 방송 송출 화면의 신호 표시가 필요해졌을 때, 샘플의 `SignalPreview.gd`(약 40줄, 기능이 단순함)로 비슷한 것을 직접 만들 수도 있다. 구매하면 풀 키트 라이선스 전문을 먼저 확인한다.
