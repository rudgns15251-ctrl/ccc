## 1. 재질 (UI 장비 표면)

**현재:** 코드로 만든 노이즈 텍스처라 마모, 긁힘, 각인이 없습니다.

**무료로 구할 것(CC0, 상용 가능, 표기 불필요)**
- [ambientCG](https://ambientcg.com): 도장 금속, 녹슨 강판, 콘크리트, 종이 텍스처. 라이선스는 CC0 1.0이며 게임에 원본 파일을 포함해도 됩니다.
- [Poly Haven](https://polyhaven.com): 고품질 금속과 표면 텍스처. 텍스처, HDRI, 모델이 CC0입니다(사이트 로고와 렌더는 제외).

**직접 만들 것**
- 위 텍스처의 색 성분만 잘라 **9-slice UI 패널**로 가공합니다(강판, 음각 홈, CRT 베젤, 종이, 경보 띠). 지금 Theme 빌더가 쓰는 파일 경로를 그대로 교체하면 됩니다.
- 디테일 오버레이: 나사 4개, 각인 라벨판, 스텐실 번호, 테이프·클립·도장 자국. 단순한 형태라 직접 그려도 충분합니다.
- 작업량: 패널 6종 + 디테일 10여 개. 1~2회 작업 분량.

**비용: 0원**

## 2. 소리

**현재:** 기계식 클릭 5종(CC0)과 CC BY 효과음 3종.

**필요한 소리**
- 조작: 무거운 토글, 다이얼, 래치.
- 종이: 넘김, 도장, 서류 내려놓기.
- 장비: CRT 전원과 고주파음, 테이프 감기, 무전 잡음과 단절음.
- 사고: 경보 루프, 원거리 금속 충격.
- 환경 루프: 환기 험, 형광등 잡음, 원거리 기계음.

**무료로 구할 것**
- **Sonniss GDC 2026 번들**: 17개 판매처의 샘플 7.47GB 이상. 무료이고 표기가 필요 없으며 프로젝트 수 제한도 없습니다. 출처는 [rekkerd](https://rekkerd.org/sonniss-releases-gdc-2026-game-audio-bundle/).
  - 주의: 2024년 번들에는 AI 학습 사용 금지 조항이 있었다는 보도가 있으므로 실제 라이선스 문서를 받을 때 확인합니다.
  - 용량이 크므로 필요한 카테고리 폴더만 골라 프로젝트에 넣습니다.
- [BigSoundBank](https://bigsoundbank.com): 3,500개 이상, CC0. 환기, 산업 스위치, 경보 계열.
- Freesound: **CC0로 표시된 파일만** 사용합니다. CC BY는 표기 관리가 번거롭고, CC BY-NC는 상용 불가라 제외합니다.

**살 것(선택, 무료 자료로 부족할 때만)**
- 타자기·사무용품 전용 팩 1개. 예를 들어 typewriter 전용 라이브러리가 판매되고 있습니다([A Sound Effect](https://asoundeffect.com/sounddesigner/Boom-Box-Library)). 대형 범용 라이브러리(예: BOOM 계열 개별 팩 약 $65~231, [Adorama](https://www.adorama.com/bby1133466.html), [Thomann](https://www.thomannmusic.com/boom_library_toons.htm))는 이 게임 규모에 과합니다.
- 예상: **0 ~ 약 10만 원**(팩 1~2개).

**직접 만들 것**
- 무전 잡음, CRT 고주파음, 테이프 감기: 노이즈와 필터 가공으로 충분히 만들 수 있습니다.
- 녹음: 종이 넘김, 도장, 서류철은 휴대폰 녹음으로도 품질이 나오는 소리입니다.
- 정리: 모든 소리를 같은 음량 기준으로 맞추고 짧은 공간 잔향을 입혀 "같은 방"에서 나는 소리로 통일합니다. 출시 품질에서는 이 작업이 소리 개수보다 중요합니다.

## 3. 게임 콘텐츠 이미지 (CCTV·실험·사고·Profile)

**현재:** T04 Master 1장과 합성 프레임 6장(임시).

- **지금 사지도 만들지도 않는 것을 추천합니다.** T04는 임시 개체이고, 정식 Case와 개체가 아직 정해지지 않았습니다. 지금 이미지를 만들면 버려질 가능성이 큽니다.
- 정식 Case 1개가 확정되면 필요 목록(Profile 1, CCTV 기본과 변화 2~3, 실험 결과 3~5, 사고 1~2)을 기준으로 외주 또는 직접 제작을 결정합니다.
- 참고 단가: 캐릭터 일러스트를 공개한 작가 가격표 기준으로 전신 약 $300, 배경을 넣으면 $100~300 추가([출처](https://bugnet.io/blog/how-much-does-indie-game-art-cost) 및 개별 작가 가격표). 같은 방·같은 개체의 변형 프레임은 원화 1장에서 파생시키면 비용을 크게 줄일 수 있습니다.
- 생성형 이미지 도구를 쓸 경우 각 도구의 상용 이용 조건과 출처 기록 정책을 따로 확인해야 합니다. 이 계획에서는 기본안으로 넣지 않았습니다.

## 4. 타이틀 아트·로고

**1차(직접, 0원)**
- 기존 승인 이미지(표준 격리실 등)와 새 재질로 타이틀 배경을 구성합니다: 어두운 감시 화면 + 장비 프레임 + 스텐실 로고.
- 로고: 동봉 글꼴(IBM Plex Sans KR / Mono)로 만든 워드마크 + 시설 표식 스타일의 간단한 기호.

**2차(외주, 출시 직전)**
- Steam 캡슐과 키 아트 기준 시장가는 중급 프리랜서 약 $300~800([presskit.gg](https://presskit.gg/field-guides/game-key-art-budget)). 인디용 캡슐을 $500~700으로 공개한 작가도 있습니다.
- 예상: **약 40만~100만 원.** 스토어 캡슐 여러 크기와 타이틀 화면을 한 번에 의뢰하는 것이 효율적입니다.
- 의뢰할 때 상용 사용권, 원본 파일 제공, 수정 횟수를 계약서에 명시합니다.

## 5. 콘솔 프레임 (화면 전체를 감싸는 장비)

- 출시작과의 이질감을 가장 크게 줄이는 요소입니다. 지금은 패널이 "업무 프로그램"처럼 보입니다.
- **직접 제작 추천:** CC0 금속 재질 위에 베젤, 나사, 환기 그릴, 표시등, 명판을 얹은 2D 프레임 1장(1920×1080). 지금의 FACILITY CONTROL 영역 배치를 그대로 따라 그리면 코드 변경은 프레임 이미지를 배경으로 까는 정도입니다.
- 외주로 할 경우 타이틀 아트 의뢰에 묶는 것이 저렴합니다.

### 2026-10-16 — 2단계 소리 적용
- 사용자 승인으로 BigSoundBank CC0 원본 26개(약 50MB)를 받아 `assets/third_party/release_ui/sfx/bigsoundbank/`(.gdignore)에 보관했습니다. 출처, 용도, SHA-256은 CREDITS.md에 있습니다.

  - 출력: `assets/ui/release/sfx/`(기존 클릭음 포함 23개, 3.4MB).
- T04 프리뷰 연결:
