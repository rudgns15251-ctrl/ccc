# Case 01 정식 문서 초안 v1 — 빛에 피부가 손상되는 개체 (2026-10-16 · DRAFT)

> 근거: `team_story_plan_analysis_v1.md` 9장(C1 PDF안 채택). 챕터1 첫 사례이자 **튜토리얼**.
> 모든 문구·수치는 [DRAFT]. 외형, 정확한 날짜·연도, 이름, 변이 경위는 확정하지 않는다(C3, C7).
> 코드·Resource는 수정하지 않았다. 아래 "7. 데이터 매핑"은 나중에 Resource를 만들 때의 기준이다.

## 1. 역할과 설계 원칙
- **학습 목표:** 프로필 → CCTV → 실험 → 격리 → 지연 결과의 한 바퀴를 배운다. "문서와 관찰이 일치하면 믿어도 된다"를 체험시키고, Case 02부터 이 신뢰가 깨진다.
- **변수 1개:** 빛. 정답 = 암실(빛 완전 차단).
- **함정은 약하게:** 튜토리얼이므로 단서가 서로 모순되지 않는다. 틀리면 시간이 지난 뒤 "왜 틀렸는지"를 기록으로 알 수 있다.
- **탈출 없음:** 오답은 `failure_without_incident`(개체 상태 악화, 탈출·방송 없음). 첫 사고방송은 챕터2의 강제 사건이 맡는다(분석 문서 4-1의 2번).
- **분량:** 문서·단서 합계를 T04의 절반 이하로. 목표 플레이 약 8분.

## 2. Profile 문서 (인게임 열람)
```
PROFILE DOCUMENT — SUBJECT 01
DOCUMENT ID: ██-01-███          [ID 형식 미정]
SUBJECT ID: 01
CLASSIFICATION: HUMANOID MUTANT / PHOTOSENSITIVE VARIANT
SECURITY LEVEL: LEVEL 1
DATE: ████.██.██                 [연도 미정, 검열 표기]
AUTHOR: ██████
STATUS: HOLDING / OBSERVATION ACTIVE
```
**1) 기본 정보**
- 접종일: ████.██.██ (검열). 접종 후 외형 변화가 점진적으로 진행됨.
- 신장 약 170cm 전후, 체형은 마른 편. 성별·연령 기록은 삭제됨.
- 피부는 얇고 창백하며 전신에 오래된 화상 같은 흔적이 있다. 눈꺼풀과 손등의 손상이 두드러진다.

**2) 일반 행동 기록**
- 밝은 곳을 피해 구석이나 구조물 그늘에 앉는다. 이동은 느리고 조용하다.
- 공격 기록 없음. 접근한 직원에게 얼굴을 돌리거나 팔로 얼굴을 가린다.
- 말을 하지는 않으나 짧은 숨소리와 낮은 소리를 낸다.

**3) 피부 반응 기록**
- 직사 조명에 노출되면 수 분 안에 붉어지고 물집이 생긴다.
- 조명 해제 후 일부 회복하지만 반복 노출 시 회복 속도가 느려진다.

**4) 관리 권고(초안)**
- 격리실은 조도 최소화를 권장한다. 정확한 기준은 추가 관찰 후 확정한다.
- 정기 검진 시 조명 사용 시간을 기록한다.

**5) 비고**
- 개체 번호 외의 식별 정보는 이송 시 분리·보관되었다. 해당 문서는 **열람 불가**.
- AUTHORIZED COPIES ONLY

> **설계 메모:** "접근한 직원에게 얼굴을 돌린다" 같은 문장은 사람이었던 흔적을 암시하되, 설정을 확정하지 않는다. 이름·마을·가족은 쓰지 않는다. 식별 정보 "분리·보관"은 챕터2 주민 명단과의 복선이다.

## 3. CCTV (표준 임시 격리실, 일반 화면 + 열화상)
카메라 표기: `CAM 01-01 · 임시 격리실`

| 관찰 시점 | 일반 화면 | 열화상(보조) |
|---|---|---|
| 00:00 | 방 구석 그늘에 웅크린 채 정지. 천장 조명 아래로 나오지 않음 | 체온 표시 정상 범위 |
| 03:10 | 조명 아래 바닥 일부가 밝은 구역. 개체는 밝은 구역을 둘러서 이동 | 변화 없음 |
| 07:40 | 같은 자세. 손으로 눈 위를 가림 | 손등 부위에 약한 열 점 |

- **단서 1:** 그늘을 선택한다(빛 회피).
- **단서 2:** 눈과 손등을 가린다(피부·눈의 민감성).
- **의도:** 튜토리얼에서는 일반 화면만으로도 답이 보이도록 하고, 열화상 탭은 "존재하며 비교할 수 있다"를 알리는 용도다. 03에서 열화상 함정이 본격 쓰인다.

## 4. 실험 (최대 3회, 공통 4종 중 선택)
> 실험 풀은 약 10종 규모로 확장 예정(C6). Case 01은 아래 4개만 제시한다. 실험 이름·표기는 [DRAFT].

| ID(안) | 이름 | 실행 | 관찰 결과 | Research 문장(안) |
|---|---|---|---|---|
| EXP_01_LIGHT | 조명 | 조명을 켜고 일정 시간 유지 후 끈다 | 즉시 몸을 웅크리고 팔로 얼굴을 가림. 노출 후 손등이 붉어짐. 조명 해제 후 천천히 풀림 | "강한 조명 노출 시 즉각적인 회피와 피부 반응이 확인되었다." |
| EXP_01_SOUND | 경보음 | 경보음을 짧게 울린다 | 고개를 한 번 돌릴 뿐 큰 변화 없음 | "경보음에 대한 반응은 제한적이었다." |
| EXP_01_TEMP | 온도 | 실온을 낮췄다 복구한다 | 약간 움츠러들지만 자세·피부 변화는 없음 | "온도 변화 자체는 주요 불안정 요인이 아니다." |
| EXP_01_APPROACH | 접근 | 직원이 다가가는 신호를 보낸다 | 얼굴을 돌리고 구석으로 물러남. 공격 행동 없음 | "접근 시 회피한다. 공격 의도는 확인되지 않았다." |

- **판정 규칙(안):** 조명 실험을 하지 않아도 프로필·CCTV 단서로 답에 도달할 수 있다. 소리·온도·접근은 "오답 방 후보를 지워 가는 용도". 3회 모두 사용해도 불이익은 없다(실험 중 개체가 탈출하는 패널티 없음).
- **조명 실험 연출:** 개체가 빛 아래에서 팔로 얼굴을 가리고 피부가 붉어진다. 사진 대신 텍스트+CRT 처리 이미지, 신체 묘사는 절제.
