## 4. 설계서의 불일치·공정성 문제 (질문)
1. **ROOM D의 오답 이유를 플레이어가 알아낼 수 없습니다.** 설계서는 D가 "저온 스트레스로 경직"이라 오답이라고 하지만, 온도를 확인하는 실험이 없습니다(습도 실험은 있음). 선택지: ① 온도 실험을 추가(예: 습도 실험을 온도 실험으로 교체), ② D를 3번째 오답 대신 제거, ③ 지금처럼 유지(추론 불가한 함정).
2. **정답 ROOM C의 조명이 "중간"입니다.** 최종 가설은 "저기류 + 방음 + **저조도**"인데 정답 방이 중간 조도이고, 저조도 방(B, D)은 오답입니다. C를 저조도로 바꾸면 D와의 차이가 온도뿐이 됩니다. 어느 쪽으로 정리할까요?
3. **A와 B의 사고 방송이 같습니다.** 둘 다 같은 사고, 같은 방송입니다. 사고를 따로 둘 필요가 있는지 확인해 주세요.
4. **실험 규모.** 5개 중 3회는 후반 규칙입니다(결정 R1: 초반은 3개 중 2회). 두 번째 사례에 이 규모가 의도된 것인지 확인해 주세요.
5. **날짜 표기.** Profile의 `1991.01.14`는 [설정 후보]입니다. 배경 연도는 미정(C7)이므로 그대로 둘지 `████`로 가릴지 정해 주세요.
6. **설계서 3절(1979년 접종, 주민 출신 성인 남성)은 게임 안 문서에 넣지 않았습니다.** Archive 문서로 만들지 알려 주세요(PDF 세계관과는 잘 맞습니다).
7. **정식 Case 02(소리 → 방음실)와의 관계.** 이 SC-01이 정식 Case 02를 대체하는지, 04~09 후보인지 결정이 필요합니다. 현재는 임시 사례로만 둡니다.
