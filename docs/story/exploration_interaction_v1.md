# 2D 모니터 안의 "탐색" 구현 방식 v1 (2026-10-17 · DRAFT · 코드 변경 없음)

> 전제: 게임은 한 대의 모니터 프로그램 안에서 진행된다. 아바타가 걸어 다니는 3D·탑뷰는 쓰지 않는다. "복도를 걷기", "환풍구에서 쪽지 찾기" 같은 행위는 **모니터가 보여 주는 것**으로 번역한다.

## 1. 기본 원칙
- 플레이어는 걷지 않는다. **카메라를 바꾸고, 화면을 확대하고, 서류를 열고, 장면 사이를 클릭으로 넘어간다.**
- 모든 탐색은 세 가지 도구만 쓴다. 제작량이 작고 UI가 일관된다.

## 2. 세 가지 탐색 도구
### A. 장면 노드 (정지 이미지 + 클릭 영역) — 프롤로그·관리실·전임자 책상
- 한 장면 = 이미지 1장 + 클릭 가능한 영역 몇 개(서류, 서랍, 가족사진).
- 이동은 장면 전환(페이드·노이즈)으로. "복도 걷기"는 복도 이미지 3~5장을 **한 걸음씩 전진 클릭 또는 자동 재생**하고 발소리·환풍기 소리를 입힌다.
- 서랍이 잠겨 있다는 상태를 보여 주고, 챕터2에서 열리게 하면 복선이 된다.
- 구현: Control 한 장 + `TextureRect` + 투명 `Button`(영역). 새 엔진 기능 없음.

### B. CCTV 핫스팟 + 확대 — 환풍구의 쪽지, 화면 구석의 기록
- CCTV 화면의 일부(환풍구 격자, 바닥의 종이)를 **마우스를 올리면 커서가 바뀌는 영역**으로 만든다.
- 클릭하면 해당 부분이 확대(크롭 + 노이즈 제거) 화면으로 열리고, 쪽지가 보이면 "회수" 버튼 또는 자동 회수로 보관함에 들어간다.
- 놓치기 쉬운 기록은 "영상 향상(밝기·대비) 슬라이더"를 써야 보이게 할 수도 있다(선택 기능).
- 구현: CCTV 이미지 위의 영역 + 별도 확대 패널. 기록 등록은 Main의 기존 Story Record 경로를 통과해야 한다(View는 요청만 한다).

### C. 시설 도면 + 카메라 이동 — 사고·복도·10칸 화면
- 시설 평면도(단순 도식) 위에 **카메라 아이콘**을 두고 클릭하면 그 카메라 영상으로 전환한다.
- 개체의 이동은 도면의 **점(블립)과 CCTV 프레임 전환**으로 표현한다. "복도를 걷는" 사고 장면도 카메라 A → B → C로 컷 전환.
- 챕터1 종료의 10칸 화면이 이 도구의 첫 사용이다.

## 3. 장면별 번역 표
| 하고 싶은 행위 | 번역 |
|---|---|
| 도착해서 복도를 걷는다 | A: 복도 이미지 3~5장 + 발소리, 독백 자막 |
| 전임자 책상을 살핀다 | A: 책상 장면 + 클릭 영역 |
| 환풍구에서 쪽지를 찾는다 | B: CCTV 핫스팟 확대 → 회수 |
| 서랍·사물에서 기록을 찾는다 | A: 책상·관리실 장면의 영역 |
| 사고 중 개체의 이동을 따라간다 | C: 도면 블립 + 카메라 전환 |
| 정전·봉인 | 화면 테마를 비상등 모드로 전환 + 전원 소리 |

## 4. 접근성·공정성
- 핫스팟은 마우스뿐 아니라 **Tab/방향키로 순회**할 수 있어야 한다(기존 키보드 포커스 규칙 유지).
- 설정에 "탐색 힌트 표시"를 두어 핫스팟 윤곽을 켤 수 있게 한다(기본은 꺼짐, 플레이어가 선택).
- 놓친 기록을 알 수 있도록 `n/12` 표시는 유지하되, 위치는 알려 주지 않는다. 회고 화면은 이후 결정.

## 5. 제작량
| 항목 | 개수 | 비고 |
|---|---|---|
| 프롤로그 정지 이미지 | 약 6~8장 | 철문, 복도 3~5장, 관리실, 책상 |
| CCTV 핫스팟 확대 이미지 | 기록 위치마다 1~2장 | 12개 기록 중 CCTV·환풍구형만 |
| 시설 도면 | 1장(+ 카메라 아이콘) | 단색 도식 |
| 전환·소리 | 기존 SFX 재사용 | 발소리, 문, 환풍기 추가 |

## 6. 구현 순서 (제안)
1. 프롤로그를 노드 장면(A)으로 TEMP 이미지와 함께 프로토타입.
2. CCTV 핫스팟(B)은 Case 02의 환풍구 일기로 한 곳만 시험.
3. 도면(C)은 챕터1 종료 10칸 화면에서 처음 사용.
- 새 시스템·Autoload 없이 Presenter와 기존 View 경로를 재사용하는 것을 원칙으로 한다.

## 7. 미정
1. 복도 걷기를 "자동 재생"으로 할지 "클릭 전진"으로 할지.
2. 영상 향상 슬라이더(B) 도입 여부.
3. 도면 화면의 시각 디자인(단색 라인 vs 사진 합성).
