## 1. PDF 요약 (사실)
- **배경:** 1991년 겨울, 소련 붕괴 직후 폐쇄도시 인근 비밀 연구소. 1979년 마을(베료좁카) 주민에게 "예방접종"으로 약물 투여 → 10여 년 관찰 → 변화가 심한 주민을 번호로 관리. **크리처 = 변한 주민.**

- **봉인 이유:** 정부가 시설을 생명유지장치만 남기고 매립. 분류 기록과 플레이어의 판단도 계속 실험 자료로 쓰임(챕터 2~3에서 드러남).
- **구성:** 프롤로그 5분 / 챕터1 정상 업무 25분(01~03) / 챕터2 균열 40분(04~07) / 챕터3 붕괴 30분(08~09 + 마지막 방송) / 에필로그 10분 = 약 110분.
- **시스템:** 프로필 → CCTV(일반·열화상) → 실험(빛·소리·온도·접근 중 최대 3) → 격리실(암실·방음실·냉각실·가열실·중격리실) → 지연 결과 → 비상방송(약 2~3분) → 다음 개체.
- **기록 12개:** 전임자 일기 6 / 주민 명단 3 / 교육 영상 원본 테이프 3. 서랍·환풍구·CCTV·실험 결과 속에 숨김.
- **중반 장치:** 중간 보고를 올리면 봉인 1단계 시작 → 출입문 잠금(떠날 수 없는 이유). 챕터 끝 "장부 9기, CCTV 10칸". 마지막에 이름이 훼손된 사원증과 가족사진을 쥔 **기록에 없는 개체(= 전임자 암시)**.
- **엔딩 5종:** 고발(명단 3 + 테이프 3), 은폐(일부 부족), 침묵(태우기), 잔류(남기기), 진엔딩(12개 전부 + 마지막 방송 직원 피해 0 + "빈 방 명패에 이름 적기").

## 4. 보완·수정이 필요한 곳
### 4-1. 기획 내부 논리
1. **진엔딩 vs "격리 실패는 엔딩에 영향 없음":** 마지막 방송은 앞선 격리 실패가 있으면 대응 대상이 늘어나므로, 실패가 간접적으로 진엔딩 가능성을 바꾼다. 규칙을 하나로 정한다. 권고: "마지막 방송의 직원 피해 0" 판정은 **기본 문항**만 기준으로 하고, 추가 대상은 최종 보고서 수치에만 반영.
2. **방송 연습 없이 마지막 방송:** 격리를 다 맞히면 첫 방송을 마지막에야 경험한다(PDF 5-2는 03 실패 시에만 안내). 권고: 챕터2에 **모든 플레이어가 겪는 스크립트 사고 1회**(기존 Step63 강제 사건 기반)로 방송 조작 안내를 넣는다.
3. **"직원 피해 0명"과 UNKNOWN:** 지금 T04는 피해를 UNKNOWN으로 둔다. 진엔딩은 **확인된 0명**이 필요하므로, 본편에서는 방송 결과 등급(적절/부분/부적절)마다 수치를 정해야 한다. T04 전문의 3단계 표를 그대로 승격하고 수치는 직원 명단이 정해진 뒤 확정.
4. **놓친 기록을 모르는 문제:** 12개 중 하나를 놓쳤는지 플레이어가 알 수 없다. 권고: 기록 보관함에 `n/12`와 빈 슬롯을 항상 표시. 은폐 엔딩의 "부족 기록 표시"는 유지.
5. **고발 조건에 일기가 불필요:** 일기 6장은 진엔딩에만 쓰인다. 일기 없이 고발해도 문제가 없으므로 일기의 동기가 약하다. 권고: 일기 일부를 고발 증거(명단·테이프와 연결)로도 사용하거나, 일기 수에 따라 고발 엔딩 후일담을 달리한다.
6. **챕터2의 수동성:** 세 가지 의심(전임자가 기록을 고침 / 크리처가 사람 / 내 기록도 쓰임)을 "발견"이 아닌 "컷신"으로 주면 약하다. 권고: 각 의심을 수집 기록 1개 이상에 반드시 연결.

### 4-3. 추론 공정성
- T04 정답(저조도 + 흡음 + 방음)은 PDF 격리실 5종에 한 칸으로 없다. **T04에서는 암실이 함정**이다. 01에서 맞았던 암실이 04에서 틀리는 점은 학습 전복으로 좋다. 대신 01~03에서 "암실이 항상 정답이 아니다"라는 단서가 CCTV/프로필에 최소 1번 필요.
