# 프롤로그 초안 v1 — 도착 · 인수인계 서류 · 안내 영상(방송 실습 1회) (2026-10-16 · DRAFT)

> 근거: PDF 5-1(프롤로그), `team_story_plan_analysis_v1.md` 9장, `case_01_draft_v1.md` 11장(방송 튜토리얼은 프롤로그 영상).

## 1. 역할
- **분위기:** 낯선 곳에 혼자 도착해 이상하게 "정돈된" 시설을 마주한다. 이 시점에는 위협이 없다. 불안은 "너무 깨끗함", "사라진 전임자", "읽어야 할 서류"에서 온다.
- **학습:** (1) 업무 순서 4단계, (2) 기록 열람과 실험·격리의 기본 조작, (3) **비상방송 콘솔 실습 1회**.
- **복선(챕터2 회수):** 전임자의 책상, 인수인계 서류의 "전출" 표기, 안내 영상의 편집 흔적(원본은 챕터2·3에서 테이프로 회수).

## 3. 장면별 내용 (문구 초안)

### P1 도착
- 화면: 눈 덮인 철문 앞, 인터폰. 문이 열리고 경비원이 서 있다.
- 경비원: "이쪽입니다."
- 문이 열리고 경비원은 안내 없이 복도 반대쪽으로 사라진다. 뒤에서 문이 잠기는 소리.
- 시스템 문구(CRT): `ARRIVAL LOGGED / 파견 직원 1명`

### P2 복도
- 환경음: 환풍기, 형광등 잔향. 음악 없음.
- 플레이어 독백 1줄(자막): "봉인될 시설이라고 했는데, 바닥에 먼지 하나 없다."
- 연출: 안내판의 글자가 모두 선명. 일부 문 위 표시등이 켜져 있다(CCTV 방 10칸 복선, 일단 4~5개만 보임).

### P3 관리실 · 인수인계 서류
**서류 1 — 인수인계 서류**
```
인수인계 서류 / 관리 담당: 번호 ███
- 인계 사유: 전임자 전출
- 대상: 잔여 개체 9기 (번호 01 ~ 09)
- 업무: 각 개체의 프로필·CCTV·실험 기록을 검토하고,
        알맞은 격리실을 선택하여 격리 완료 후 최종 보고서를 제출할 것
- 제출 기한: 봉인 개시 전
- 비고: 기록 열람은 지정 콘솔에서만 허용
```
- 설계 메모: "관리 담당: 번호 ███"은 챕터2에서 플레이어의 사번 형식과 같은 것으로 회수된다(PDF 5-3). 지금은 검열.

**서류 2 — 봉인 명령서**
```
봉인 명령서
- 대상 시설 전체
- 생명유지장치를 제외한 모든 설비의 가동을 중지하고,
  구조물 전체를 봉인한다.
- 봉인 개시 시점은 최종 보고서 접수 이후로 한다.
- 문의처: 없음
```
- 설계 메모: 이 시점에는 봉인 이유를 쓰지 않는다("문의처: 없음"이 불안 장치).

### P4 전임자의 책상
- 사물: 마시다 만 머그컵, 눌러 끈 담배, 접힌 가족사진(얼굴은 접힌 면에 가려 보이지 않음), 훼손된 이름표.
- 서랍은 열리지 않는다(챕터2 회수 지점).
- 인수인계 서류 속 "전출"과 책상의 생활감이 어긋나는 점이 핵심. **기록 수집 항목은 두지 않는다**(기록은 02부터).
- 선택 확인. 안 봐도 진행에 문제 없음.

### P5 안내 영상 (비디오테이프)
화면은 CRT 안에서 재생되는 낡은 영상(주사선, 트래킹 노이즈). 자막과 내레이션은 같은 문구.

**영상 1부 — 업무 순서 (약 40초)**
> 내레이션: "개체 번호가 부여되면 다음 순서로 업무를 진행하십시오. 첫째, 프로필 확인. 둘째, CCTV 확인. 셋째, 실험. 넷째, 격리."
- 영상 속 화면에 실제 UI 4칸(프로필·CCTV·실험·격리)이 순서대로 강조된다.
- 플레이어 조작: 없음(시청). 스킵 가능.

**영상 2부 — 실험과 격리 (약 40초)**
> 내레이션: "실험은 개체마다 최대 3회입니다. 모든 실험이 필요하지는 않습니다. 격리실은 한 번 선택하면 변경할 수 없습니다. 결과는 즉시 알려 드리지 않습니다."
- 규칙 전달: 3회 제한, 변경 불가, 지연 결과(핵심).

**영상 3부 — 비상방송 (약 40초 + 실습)**
> 내레이션: "격리가 실패해 개체가 이탈하면 비상방송이 필요합니다. 방송은 시설을 조작하는 것이 아니라 직원에게 대피 지침을 전달하는 것입니다. 상황을 읽고, 지침을 고르고, 원고를 확인한 뒤 송출하십시오. 송출 후에는 수정할 수 없습니다."
- 이어서 **모의 방송 실습**(아래 4장). 실습 후 영상이 재개되어 마무리 문구.

**영상 마무리 (약 10초)**
> 내레이션: "이상, 업무를 시작하십시오."
- 화면 끝에서 잠깐 영상이 끊긴다(1초 미만의 검은 화면). 이 편집 흔적은 챕터2에서 "몇 초가 잘린 채 다시 등장"하는 복선이다. **프롤로그에서는 설명하지 않는다.**

### P6 업무 개시
- 책상 위에 Case 01 프로필이 놓인다. 알림 문구: `SUBJECT 01 / 열람 가능`.
- 이후 Case 01 문서(case_01_draft_v1.md)로 진행.

## 4. 방송 실습 (모의, 1회)
> 목적: 방송 콘솔의 **전 과정**(상황 확인 → 질문 → 지침 선택 → 원고 미리보기 → 확인 → 송출 → 잠금)을 한 번 겪는다. 기록·저장·엔딩에 **영향 없음**.

**모의 상황 (영상 속 가상 사고, 개체 번호 없음)**
> 훈련 상황: 격리동 복도에서 개체 이탈이 확인되었습니다. 인근 직원 일부가 복도에 있습니다.
> 질문 1. 직원에게 어떤 지침을 전달해야 합니까?
> A. 개체의 위치를 큰 소리로 서로 알리며 이동한다.
> B. 개체와 거리를 유지하고, 지정된 대피 구역으로 이동한 뒤 문을 닫는다.
> C. 개체를 확인하기 위해 복도에 남는다.

- **정답:** B. 오답 A·C 선택 시 영상 안내자가 짧게 정정한다: "다시 선택하십시오(실습)". 실습에서는 틀려도 재선택 가능(본 게임에서는 불가).
- 확인 단계에서 원고 미리보기가 표시되고, "확인" 후 송출·잠금 연출을 그대로 체험.
- 결과 화면에는 "실습 종료"만 표시하고 피해·사고 기록은 만들지 않는다.
- **설계 원칙:** 실습 정답이 본 게임의 특정 사례 정답과 겹치지 않게 일반 원칙("거리 유지·대피 구역·문 닫기")만 다룬다. 방송 시설 제어를 대신하는 UI가 아님을 영상이 한 번 강조한다.

### 방송 실습에 포함하지 않는 것
- 복수 질문(본 게임은 2문항 이상): 실습은 1문항. 복수 질문 흐름은 첫 실전에서 배우되 UI 안내 한 줄("질문이 더 있습니다")을 둔다.
- 사망·부상 수치, 사고보고서.

## 7. 미정·확인 필요 (사용자 결정)
1. **플레이어의 시점·정체:** 이름·성별·사번 표기 여부. 현재는 사번 ███ 검열만.
2. **경비원의 말:** 한마디만 둘지, 아예 무언인지.
3. **방송 실습 정오 처리:** 오답 시 정정 후 재선택(현재안) vs 정답 안내만.

6. **독백(P2):** 플레이어 내면 독백 자막을 쓸지(톤이 설명적이 될 수 있음).

### 결정에 따른 수정 사항
- **4장 방송 실습 폐기:** 5장의 "방송 실습은 분리된 모드 필요" 항목이 사라져 엔진 부담이 줄어든다. 대신 강제 이벤트가 **실제 방송 흐름**(Campaign 상태에 기록됨)을 처음 쓰게 된다.
- **강제 이벤트와 안전장치:** 첫 실전 방송에서 틀려도 치명적이지 않게 설계해야 한다. 후보: 챕터1 말미 또는 챕터2 초반의 스크립트 사고(기존 Step63 강제 사건). 이벤트 전에 영상 3부의 설명(방송은 지침 전달, 송출 후 수정 불가)을 다시 짧게 상기시키는 UI 한 줄이 필요하다.
- **영상 3부 문구 수정(안):** 내레이션 마지막에 "실제 상황에서 연습은 없습니다"를 넣어 이후 이벤트의 긴장감을 예고한다.
- **영상 4 제작 사양:**
  - 픽토그램: 프로필·CCTV·실험·격리·방송 5개, 단색 라인.
  - 음성: 러시아어 TTS, 한국어 자막. 챕터2에서 자막과 음성이 어긋나는 장면(PDF)이 자연스럽게 구현된다.
  - 영상 끝의 1초 암전은 유지(챕터2 잘린 장면 복선).
  - 필터: CRT 주사선, 디더링, 트래킹 노이즈. 기존 아날로그 호러 UI·SFX 자산 재사용.
- **권한 확인:** 러시아어 TTS는 사용할 도구의 상업 이용·재배포 조건을 먼저 확인한다(미확인). 생성 음성은 출처와 조건을 `assets/` 출처 문서에 기록한다.
