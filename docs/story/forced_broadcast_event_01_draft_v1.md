# 강제 방송 이벤트 #1 초안 v1 — INC_CH2_01 (2026-10-17 · DRAFT)

> 근거: `case_02_draft_v1.md` 11장(단일 스크립트, 대상 = Case 02의 방), `case_03_draft_v1.md` 7장(챕터1 종료 연출), `prologue_draft_v1.md` 8장(방송 실습 없음).
> 모든 문구는 [DRAFT]. 사망·부상 수치는 정하지 않는다(UNKNOWN 유지). 코드·Resource는 수정하지 않았다.

## 1. 역할
- **첫 실전 방송.** 플레이어는 프롤로그 영상 설명만 들었고 연습이 없다. 이 이벤트가 방송 콘솔의 첫 사용이다.
- **모든 플레이어가 같은 사건을 겪는다.** 원인은 시설 노후 설비 결함이며 플레이어의 격리 판단이 아니다.
- **긴장 곡선:** 챕터1의 조용한 업무 뒤에 처음으로 시설이 "움직이는" 순간. 설명은 짧게, 공포는 소리와 CCTV로.
- **분량:** 약 3분. 질문 2개(선택 4지).
- **불변 계약:** 방송은 직원 대피·생존 지침이며 시설 제어 UI가 아니다. 격리 `SUCCESS`와 `실제 탈출`은 별개의 사실이다. 사망자 `UNKNOWN`과 확인된 0명을 구분한다.

## 2. 위치와 진입
```
… Case 03 격리 승인
→ 챕터1 종료 연출(장부 9 / CCTV 10칸 / 긁는 소리)
→ 챕터2 시작 화면
→ 【강제 방송 이벤트 #1】  (Campaign의 스크립트 사건 항목)
→ 사고 결과 확인 → 업무 복귀
→ Case 04
```
- 이 이벤트는 Case 02의 `failure_without_incident` 여부와 무관하게 발생한다.
- **알림 문구(진입 시 1줄):** "방송 콘솔 사용 · 상황을 읽고, 지침을 고르고, 송출 후에는 수정할 수 없습니다." (프롤로그 영상 3부의 상기)

## 3. 사건 진행 (단계)
| 단계 | 화면 | 내용 |
|---|---|---|
| P0 | 챕터2 시작 | 시설 전체가 짧게 정전·재가동. 환풍기 소리가 한순간 멈췄다 켜진다 |
| P1 | 시스템 경고 | `B구역 02 격리실 출입문 잠금 상태: FAULT`. 경고 문구는 단순 상태 표기만 |
| P2 | 자동 경보 | 사이렌과 점멸등이 **자동으로 작동**한다. CCTV 02 화면: 문이 반쯤 열려 있고, 02가 귀를 막고 복도로 나와 벽에 몸을 부딪힌다 |
| P3 | 사고 화면(INCIDENT) | `INC_CH2_01 / 개체 02 이탈`. 위치 B구역 복도, 인근 직원: 보안 2명, 설비 1명(인원 수는 DRAFT) |
| P4 | 방송 | 질문 2개, 원고 미리보기, 확인, 송출, 잠금 |
| P5 | 결과 | 사고 보고서(INCIDENT_RESULT), 업무 복귀 |

- **핵심 연출:** 사이렌이 켜질수록 02가 더 거칠게 움직인다. 플레이어가 "경보가 문제다"를 **눈과 귀로 알 수 있게** 한다(설명 문구 없음).
- 시간 기반 타이머는 사용하지 않는다(진행은 플레이어의 읽기·행동 경계에서만).

## 4. 방송 질문
> 공통 상황 패널: "B구역 복도 CCTV. 02가 복도에서 귀를 막고 벽에 부딪히고 있습니다. 자동 사이렌과 점멸등이 작동 중입니다. 인근에 보안 2명과 설비 1명이 있습니다."
> 기록 패널: Case 02에서 확보한 기록(CCTV·실험·Research)이 있으면 그대로 열람 가능. 새로운 정답 힌트는 이 화면에서 추가하지 않는다.

### Q01. 직원에게 알리는 방식
> 질문: 인근 직원에게 어떤 방식으로 대피를 알립니까?

| | 선택지 | 판정 |
|---|---|---|
| A | 사이렌을 유지하고 방송 음량을 높여 전 구역에 알린다 | 부적절 |
| B | 사이렌을 정지하고, 소리 없는 표시등과 낮은 음량의 무전으로 대피 구역을 알린다 | **정답** |
| C | 사이렌을 끄고 알림을 중단한 채 상황을 지켜본다 | 부적절 |
| D | 사이렌을 정지하고 직원들이 큰 소리로 서로에게 알린다 | 부적절 |

- **실제 방송 문장(정답 B):** "통제실이다. 사이렌을 정지한다. 이후 지시는 소리 없는 표시등과 낮은 음량의 무전으로 전달한다. 큰 소리와 금속음을 내지 마라."
- 오답 결과의 의도:
  - A: 02가 더 흥분하고 접근 범위가 넓어진다.
  - C: 직원이 상황을 알지 못해 복도에 남는다.
  - D: 고함이 02를 자극한다.

### Q02. 접근 판단
> 질문: 보안 인원 2명이 02를 확보하려 합니다. 어떤 지침을 전달해야 합니까?

| | 선택지 | 판정 |
|---|---|---|
| A | 2인 1조로 접근해 제압한다(프로필의 접근 지침을 따른다) | 부적절 |
| B | 접근하지 않고 거리를 유지한 채, 소리 없이 차단문 안쪽 대피 구역으로 이동하고 문을 닫는다 | **정답** |
| C | 호루라기로 02의 주의를 끌어 한쪽으로 유도한다 | 부적절 |
| D | 금속 막대로 벽을 두드려 02의 움직임을 멈추게 한다 | 부적절 |

- **실제 방송 문장(정답 B):** "보안 인원은 대상에게 접근하지 마라. 거리를 유지하고, 소리를 내지 않은 채 차단문 안쪽 대피 구역으로 이동하라. 이동이 끝나면 문을 닫아라."
- 오답의 의도:
  - A: 프로필의 "2인 1조 접근"을 그대로 따르는 함정. 02의 체격과 팔 휘두름으로 부상.
  - C·D: 소리 자극이 02의 반응을 키운다(Case 02의 경보음 실험과 연결).

- **사고 보고서 예시:**
  > 사고 기록 / INC-CH2-01  LEVEL 2
  > 사고 원인: B구역 02 격리실 출입문 잠금 장치의 노후(설비 결함) 및 자동 경보 사이렌 작동에 의한 개체 흥분.
  > 초기 조사 결과: 출입문 잠금 이상이 확인됨. 개체의 공격 의도는 확인되지 않음.
  > 대응 결과: 방송 지침 수행 결과에 따라 기재.
  > 관리 부서 소견: 사고 원인은 개체의 행동이 아니라 설비 결함과 경보 환경이 결합된 결과로 판단됨.
- **02의 판정과의 관계:** 02의 사전 상태(방음실 `SUCCESS` 또는 오답 후 악화)는 보고서의 "대상 사전 상태" 한 줄로만 표시한다. 이 사건은 02의 **격리 판정을 바꾸지 않는다**. 방음실이던 02도 설비 결함으로 탈출한 것이 사실이다.
