2026-10-16. 이 문서의 신규 내용과 게임에 반입한 T04 콘텐츠는 모두 **TEMP / DRAFT / NON-CANON**이다. 정식 Case·인간 기원·접종·시설 역사·엔딩 설정으로 승인하지 않았다.

## 유지한 내용

Profile은 문서 ID `BR-04-112`, SUBJECT T04, 날짜·작성자·검열, 단일 흉곽/체간/골반, 두 두부/네 상지/두 하지, 추정 신장, 장시간 정지, 구조물 접촉, 두부별 자극 반응, 복합 자극 협응 저하, 얽힘·견인 사고, 초기 오판과 정정, 관리 권고를 포함한다. 해당 문서의 검열·보안 등급도 정식 세계관 사실이 아닌 TEMP 원문 표기다.

돌기의 감각 기능과 두부 기능 분화는 가설로 남긴다. 독립 신경계·내부 장기·지능적 잠금 해제를 추가하지 않았다. Master 실루엣을 변경하지 않았으며 신장 수치를 사진으로 검증했다고 주장하지 않는다.

실험 ID 5개, Room ID 3개, Incident `INC_T04_01`, Research ID 23개는 유지했다. Case ID는 정식 편입과 구분하기 위해 `TEMP_T04_CASE`, 저장 Campaign ID는 `TEMP_T04_M5B_PLAYTEST`로 정했다.

## 아직 필요한 승인·제작

T04 정식 편입, 문서의 역사·작성자·보안 수준, 두부/돌기의 생리 가설, ROOM B 결함, 대피 지시의 최종 문장, 실제 피해 규모는 승인 대기다. 현재 구현으로 이를 본편 사실로 확정하지 않는다.

전용 Profile 촬영본, CCTV Anchor/열화상, 실험 결과 5장, 후보별 환경, ROOM B 사고·사고보고서 증거 이미지는 미제공이다. 기존 Placeholder와 실제 텍스트를 유지한다. 새로운 실험/사건 사진을 생성하거나 다른 개체 이미지를 대체 사용하지 않았다.
