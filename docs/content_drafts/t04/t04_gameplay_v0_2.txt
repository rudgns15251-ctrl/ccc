# CASE T04 — 격리 조건·실험·사고 시스템 상세 설계 v0.2

설정 후보 · 승인 대기

기존에 설계한 두 개의 머리, 네 개의 팔을 가진 복합 감각형 개체 T04를 기준으로 격리 조건과 게임플레이를 구체화했습니다.

이번 설계에서 가장 중요한 것은 단순히 빛과 소리를 싫어하는 개체로 만들지 않는 것입니다.

T04는 두 머리가 서로 다른 자극을 처리하며, 자극이 일정 수준을 넘으면 사지의 움직임을 조율하지 못하는 개체로 설정합니다. 이것이 장기 격리 실패와 탈출 사고의 원인이 됩니다.

## 1. 격리 조건 확정안

### 핵심 생리 원리 [설정 후보]

| 신체 구조       | 생리적 기능 가설          | 관찰되는 행동                   |
| ----------- | ------------------ | ------------------------- |
| 왼쪽 웃는 머리    | 청각·진동 자극에 우선 반응    | 입을 벌리고 긴 팔로 주변 구조물을 탐색    |
| 오른쪽 큰 눈의 머리 | 시각적 변화와 움직임에 우선 반응 | 광원과 움직이는 물체를 지속적으로 추적     |
| 네 개의 팔      | 공간 탐색과 신체 균형 유지    | 서로 다른 방향으로 움직이며 벽과 설비에 접촉 |
| 공유 몸통       | 두 머리의 운동 반응을 통합    | 자극이 과도해지면 사지 협응성 저하       |

두 머리의 감각 기능 분화는 실제로 관찰되는 반응을 설명하기 위한 가설입니다. 독립된 신경계나 내부 장기 구조까지 확인된 것은 아닙니다.

### 환경별 반응

| 환경 조건                 | 개체 반응                 | 장기 격리 적합성  |
| --------------------- | --------------------- | ---------- |
| 저조도 + 흡음 + 외부 소음 차단   | 탐색 운동 감소, 장시간 정지      | 적합         |
| 저조도 + 반향이 큰 금속 벽면     | 소리 발생 시 상지 탐색 증가      | 부적합        |
| 일반 조도 + 일반적인 소음 환경    | 움직임과 탐색 행동이 반복됨       | 부적합        |
| 고조도 + 조용한 환경          | 시각적 경계·추적 행동 유지       | 장기 안정성 불충분 |
| 완전 암실 + 큰 반향          | 시각 추적은 감소하지만 음향 탐색 지속 | 부적합        |
| 저조도 + 흡음 + 지속적인 기계 진동 | 진동 강도에 따라 접촉 행동 증가    | 조건부        |

여기서 방음과 흡음은 구별해야 합니다.

- 방음: 외부에서 발생한 소리가 격리실 안으로 전달되는 것을 줄입니다.
- 흡음: 격리실 안에서 발생한 소리가 벽에 반사되어 오래 남는 현상을 줄입니다.

따라서 방음만 강하고 내부가 금속 재질이라 소리가 심하게 울리는 방은 정답이 아닙니다.

### 단일 자극만으로도 실패할 수 있는가?

가능합니다. 다만 단일 자극과 복합 자극의 위험도를 구분합니다.

| 자극           | 순간적인 반응             | 지속적인 노출         |
| ------------ | ------------------- | --------------- |
| 짧은 금속 충격음 1회 | 왼쪽 머리 반응, 팔 움직임 증가  | 자극 종료 후 회복      |
| 강한 반향음 반복    | 주변 구조물 탐색 증가        | 단독으로도 격리 실패 가능  |
| 일정한 밝은 조명    | 오른쪽 머리 경계·주시        | 단독으로는 탈출 가능성 낮음 |
| 반복되는 이동광     | 시선 추적과 일부 상지 움직임 증가 | 장기 안정성 저하       |
| 이동광 + 반향음    | 두 머리 반응 충돌, 협응성 저하  | 가장 빠른 불안정화      |
| 약한 기류 변화     | 팔끝과 머리 움직임          | 일반적으로 실패 원인 아님  |

추천하는 핵심 규칙은 다음과 같습니다.

1. 반향성 음향 자극은 충분히 강하고 반복되면 단독으로도 실패를 유발할 수 있습니다.
2. 시각 자극만으로는 감시·탐색 행동이 증가하지만, 정상적인 시설 환경에서는 즉각적인 탈출까지 연결하지 않습니다.
3. 시각과 음향 자극이 동시에 발생하면 불안정화 속도가 크게 증가합니다.
4. 한 번의 갑작스러운 자극은 경계 반응으로 처리하며, 곧바로 격리 실패로 판정하지 않습니다.

이는 플레이어에게 중요한 구분을 제공합니다.

자극에 반응한다는 것과 그 환경에서 격리할 수 없다는 것은 서로 다른 문제입니다.

## 2. 실험 5종 — 실제 게임 결과

모든 실험은 [설정 후보]이며, 기존 Experiment 구조와 최대 3회 수행 제한을 유지합니다.

실험은 모두 표준 임시 격리실에서 원격으로 실행합니다. 기본 조도와 온습도, 환기 조건을 유지하다가 해당 실험에 필요한 변수만 변경하는 방식입니다.

### EXP_T04_ECHO — 음향 반향 비교

핵심 실험

목적: 소리의 크기 자체보다 반향과 반복이 행동에 어떤 영향을 주는지 검증합니다.

실행 과정:

1. 격리실 스피커에서 짧은 금속 충격음 1회 출력
2. 개체의 반응을 관찰
3. 동일한 최대 음량의 충격음에 잔향을 추가한 신호를 재생
4. 두 조건의 행동을 비교

여기서 두 번째 신호는 실제 벽면을 교체하는 것이 아니라, 녹음된 반사음을 추가한 시험 신호입니다.

| 구분        | 실제 결과                            |
| --------- | -------------------------------- |
| 단발 충격음    | 웃는 머리 회전, 상부 팔 1\~2개 반응          |
| 잔향이 있는 신호 | 웃는 머리의 반복적인 회전, 상부 팔 2개가 벽면을 탐색  |
| 자극 중단     | 탐색 행동이 서서히 감소                    |
| 주요 관찰     | 동일한 최대 음량에서도 잔향을 포함한 신호에 더 오래 반응 |

화면 연출: 개체의 웃는 머리가 스피커 방향으로 돌아간 뒤, 소리가 멈춘 후에도 팔이 벽면을 두세 차례 더 접촉합니다.

Research Log

> 단발성 음향과 잔향 포함 음향에 대한 반응 차이 확인. 잔향 조건에서 두부 회전 및 상지의 구조물 접촉 행동이 더 오래 지속됨.

추론: 단순히 조용한 방을 선택하는 것보다 반향이 적은 방을 선택해야 할 가능성이 있습니다.

### EXP_T04_LIGHT — 이동광 추적

목적: 오른쪽 머리의 시각 반응과 단독 시각 자극의 위험성을 확인합니다.

실행 과정:

1. 일정한 기본 조도를 유지
2. 벽면에 약한 이동광 조사
3. 광원의 방향을 천천히 변경
4. 자극 종료 후 움직임 비교

| 구분     | 실제 결과                       |
| ------ | --------------------------- |
| 일정한 조명 | 머리의 움직임 적음                  |
| 이동광 발생 | 큰 눈의 머리가 즉시 광원 추적           |
| 이동광 지속 | 목 회전과 한쪽 팔의 움직임 증가          |
| 자극 종료  | 시선 추적 감소, 자세 안정             |
| 주요 관찰  | 전신의 과도한 탐색이나 협응 붕괴는 발생하지 않음 |

화면 연출: 큰 눈의 머리만 천천히 움직이는 광원을 따라갑니다. 웃는 머리는 거의 움직이지 않습니다.

Research Log

> 이동광 자극에 대한 B두의 지속적인 추적 행동 확인. 단독 시각 자극에 의한 전신 운동 증가는 제한적임.

추론: 빛이 자극이라는 것은 확인되지만, 빛만으로 개체가 통제 불가능해지는 것은 아닙니다.

### EXP_T04_COMBINED — 복합 감각 부하

가장 강한 행동 반응

목적: 시각과 음향 자극이 동시에 발생했을 때 협응성 변화를 확인합니다.

실행 과정:

1. 이동광을 한쪽 벽에 조사
2. 반대쪽 스피커에서 잔향성 음향 출력
3. 두 자극을 짧은 시간 동안 중첩
4. 원격 제어로 자극 종료

| 구분    | 실제 결과                  |
| ----- | ---------------------- |
| 자극 초기 | 두 머리가 서로 반대 방향으로 회전    |
| 자극 중첩 | 네 팔의 움직임이 동시에 증가       |
| 중첩 지속 | 일부 팔이 교차하고 몸통의 균형이 흔들림 |
| 자극 종료 | 움직임이 감소하며 균형 회복        |
| 주요 관찰 | 단일 자극보다 상지 협응성이 크게 저하  |

화면 연출: 오른쪽 머리는 벽의 빛을 응시하고, 웃는 머리는 소리가 들리는 방향을 향합니다. 두 머리의 방향과 네 팔의 움직임이 점점 어긋납니다.

Research Log

> 복합 자극 조건에서 두 두부의 지향 반응이 분리됨. 상지의 교차 운동과 구조물 접촉이 증가했으며, 단일 자극 조건보다 자세 협응성이 낮아짐.

추론: 복합 감각 자극이 가장 위험한 불안정화 요인이라는 가설이 지지됩니다.

이 실험의 반응은 강하지만, 정상적인 절차에 따라 자극을 중단하면 회복됩니다. 실험을 선택했다는 이유만으로 탈출 페널티가 발생하지 않습니다.

### EXP_T04_LOWSTIM — 저자극 환경 반응

목적: 감각 자극의 총량을 줄였을 때의 회복·안정화 가능성을 검증합니다.

실행 과정:

1. 조도를 낮은 수준으로 조절
2. 비필수 스피커와 실험장치 정지
3. 필수 환기 및 감시장치 유지
4. 개체의 움직임을 일정 시간 관찰

| 구분       | 실제 결과                    |
| -------- | ------------------------ |
| 조도 감소 직후 | 큰 눈의 머리 회전 감소            |
| 음향 자극 중단 | 웃는 머리의 회전과 발성 감소         |
| 관찰 지속    | 상지 탐색 행동 감소              |
| 최종 상태    | 장시간 정지, 팔끝의 미세 움직임만 유지   |
| 주요 관찰    | 저자극 환경에서 행동이 가장 안정적으로 감소 |

화면 연출: 개체가 격리실 중앙에 정지하고, 네 팔이 서로 다른 높이에서 느리게 내려갑니다.

Research Log

> 외부 시각·음향 자극 감소 후 상지 탐색 빈도 및 두부 회전 빈도가 감소함. 저자극 상태에서는 장시간 정지 자세를 유지함.

추론: 환경 자극 감소가 안정화에 효과적입니다.

다만 이 실험은 현재 임시 격리실의 소음을 줄이는 실험입니다. 벽면 흡음 성능 자체를 바꾸지는 않으므로, 반향 감소의 중요성은 음향 실험과 함께 판단하게 됩니다.

### EXP_T04_AIR — 기류 변화 실험

목적: 긴 팔과 두부 주변 돌기들이 기류를 감지하는지, 기류가 주요 불안정화 조건인지 확인합니다.

실행 과정:

1. 기본 환기 상태에서 관찰
2. 송풍량을 제한된 범위에서 증가
3. 기존 환기 상태로 복구

| 구분       | 실제 결과                        |
| -------- | ---------------------------- |
| 송풍 초기    | 팔끝과 머리 주변 부속 구조가 미세하게 움직임    |
| 송풍 지속    | 개체가 일부 상지를 송풍 방향으로 회전        |
| 기본 기류 복구 | 움직임 감소                       |
| 주요 관찰    | 강한 전신 불안정화 없이 제한적인 지향 반응만 발생 |

화면 연출: 개체가 송풍구 쪽으로 한쪽 팔을 천천히 뻗습니다. 두 머리의 방향은 크게 변화하지 않습니다.

Research Log

> 기류 변화에 따른 말단부 움직임과 상지의 지향 반응이 확인됨. 관찰된 조건에서 전신 협응성 저하나 급격한 탐색 행동 증가는 확인되지 않음.

추론: 기류 감지는 가능하지만, 주요 격리 실패 원인으로 보기는 어렵습니다.

## 3. 실험 선택 제한과 추론 공정성

플레이어에게 제공되는 실험은 5개이며, 한 Case에서 최대 3개를 수행할 수 있습니다.

다음은 대표적인 선택 조합입니다.

| 선택 조합                      | 획득하는 핵심 정보                | 정답 추론 |
| -------------------------- | ------------------------- | ----- |
| ECHO + LIGHT + COMBINED    | 음향 반향, 단독 시각 반응, 복합 자극 위험 | 매우 명확 |
| ECHO + AIR + LOWSTIM       | 반향이 위험하며 저자극이 유리함         | 명확    |
| LIGHT + COMBINED + LOWSTIM | 복합 자극 위험과 안정화 방향          | 명확    |
| LIGHT + AIR + ECHO         | 반향의 중요성과 단독 자극의 차이        | 가능    |
| AIR + LIGHT + LOWSTIM      | 기류는 주원인이 아니며 저자극이 유리함     | 가능    |

중요한 설계 조건: 세부 생리적 원리까지 모든 실험 조합에서 확인할 필요는 없지만, 플레이어가 적절한 격리실을 선택하는 데 필요한 정보는 얻을 수 있어야 합니다.

이를 위해 기본 Profile과 CCTV에 다음 단서를 배치합니다.

- Profile: 과거 소음이 발생한 환경에서 구조물 접촉 행동 증가
- CCTV: 일상적인 시설 소음 발생 시 웃는 머리의 반응 확인
- CCTV: 밝은 부분이나 움직이는 광원을 큰 눈의 머리가 추적
- 과거 기록: 완전히 조용해진 환경에서는 움직임 감소

따라서 관련 없는 실험을 선택하더라도 핵심 정보를 전부 잃지는 않습니다.

## 4. 격리실 후보 3개

이전 4개 후보를 3개로 정리했습니다. 각 격리실의 차이는 단순한 조명 세기가 아니라 시각 자극과 소리의 반사·유입 조건에 있습니다.

## 5. 격리 실패와 탈출 과정

### Incident ID: INC_T04_01

발생 조건 [설정 후보]: ROOM B에 배치한 뒤, 반복적인 음향 반응으로 불안정화가 진행되는 경우입니다.

사고는 격리 승인 직후 발생하지 않습니다. 플레이어가 다음 업무를 수행하는 동안 시스템 경고와 CCTV 화면을 통해 점진적으로 진행됩니다.

1. PHASE 0 — 격리 직후

   STATUS: OBSERVATION ACTIVE

   개체는 저조도 환경에서 직립 정지합니다. 팔끝의 움직임만 확인됩니다.

   플레이어에게 안정적으로 보일 수 있지만 성공 여부는 표시하지 않습니다.
2. PHASE 1 — 반복적인 음향 반응

   STATUS: MOVEMENT INCREASED

   기계의 주기적인 충격음에 왼쪽 머리가 반복적으로 반응합니다. 두 상부 팔이 벽면을 접촉하기 시작합니다.

   연구 시스템에는 단순한 행동 증가 기록만 남깁니다.
3. PHASE 2 — 구조물 접촉 증가

   STATUS: STRUCTURAL CONTACT DETECTED

   긴 손가락이 배관 지지대와 출입문 주변 점검 패널을 반복적으로 접촉합니다.

   CCTV에서는 오른쪽 머리가 출입문 상단의 표시등을 응시하는 모습이 확인됩니다.
4. PHASE 3 — 설비 이상

   STATUS: MAINTENANCE PANEL FAULT

   반복적인 접촉으로 기존에 고정 상태가 불량했던 점검 패널이 이탈합니다. 내부의 비상 해제 기구가 노출되고, 개체의 긴 손가락이 여기에 걸립니다.

   잠금장치가 비정상적으로 해제되며 출입문이 일부 개방됩니다.
5. PHASE 4 — 격리 이탈

   STATUS: CONTAINMENT BREACH

   개체가 열린 틈을 통해 복도로 이동합니다. 이때 네 팔을 벽면과 천장 쪽으로 뻗어 주변 구조물을 접촉합니다.

   시설 통제 시스템에서 격리 이탈이 확인되면 Incident가 발생합니다.

이 탈출 방식에는 한 가지 전제 조건이 필요합니다. ROOM B의 점검 패널과 비상 해제 기구가 구조적으로 취약하다는 것입니다.

T04가 특별한 지능으로 도어 잠금장치를 해제하는 것이 아니라, 반복적인 구조물 탐색이 기존의 설비 결함과 맞물리면서 사고가 발생하도록 설계합니다. 이는 Incident 전용 시설 결함 설정이며 아직 [설정 후보]입니다.

복도의 조명과 음향, 주변 구조물에 따라 다음과 같은 행동을 보입니다.

### 피해 양상

이번 사고의 피해는 물어뜯기보다 얽힘, 견인, 충돌, 압박으로 발생합니다.

예를 들어 경비 직원이 격리동을 이탈하는 과정에서 개체의 팔에 보호복 스트랩이 걸립니다. 직원이 빠르게 움직일수록 걸린 장비가 당겨지며, 옆에 있던 직원까지 넘어질 수 있습니다.

개체가 사람을 공격했다는 사실보다는, 개체가 사람의 신체와 장비를 주변 구조물처럼 접촉하고 끌어당긴다는 점을 공포 요소로 사용합니다.

이러한 행동은 기존 Profile의 사고 기록과 연결되므로 새로운 능력을 추가할 필요가 없습니다.

## 6. Emergency Broadcast — 직원 대피 지침

방송 대상은 격리동 연구원과 경비·시설 관리 인원입니다.

방송 선택지는 3개 문항으로 설계하되, 본편의 진행 속도를 고려하면 Q01과 Q02를 필수 문항으로 사용하고 Q03은 조건부 문항으로 활용하는 것을 추천합니다.

### Q01. 격리동 직원의 즉시 대피

상황

대상 T04가 격리동 복도에서 확인되었습니다. 인근 직원들이 여러 방향으로 대피 중이며, 일부 직원이 손전등과 무전기를 사용하고 있습니다.

질문: 인접 구역 직원에게 어떤 지침을 전달해야 합니까?

A. 손전등을 이용해 개체의 위치를 지속적으로 확인하며 단체로 이동한다.

B. 큰 소리로 위치를 공유하고 가장 가까운 복도 출구로 뛰어간다.

C. 불필요한 발성과 이동광 사용을 중단하고, 개체와 거리를 유지하며 차단 가능한 구역으로 후퇴한다.

D. 금속 장비를 던져 개체의 주의를 돌린 뒤 반대편 출구로 이동한다.

실제 방송 문장 — 정답 C

> 격리동 직원에게 알린다. 이동광 사용과 불필요한 발성을 중지하라. 대상과의 거리를 유지하고, 지정된 차단 구역으로 이동한 뒤 출입문을 폐쇄하라.

### Q02. 시설 제어와 대피 경로 확보

상황

T04가 금속 배관이 많은 B구역 복도에 머무르고 있습니다. 자동 경보음과 반복 점멸등이 작동하고 있습니다.

질문: 시설 관리팀이 우선 실행할 조치는 무엇입니까?

A. 경보음을 최대 음량으로 유지해 전 직원에게 위험을 알린다.

B. 전체 조명을 즉시 차단하고 모든 출입문을 일괄 개방한다.

C. 안전상 필요한 경보는 유지하면서, 해당 구역의 비필수 음향·점멸 자극을 줄이고 차단문을 원격 폐쇄한다.

D. 환기팬의 속도를 최대치로 높여 개체의 이동 방향을 바꾼다.

실제 방송 문장 — 정답 C

> 시설 관리팀은 B구역의 비필수 음향 장치와 점멸등을 정지하라. 대피 구역의 필수 조명을 유지하고, 직원 이동이 완료된 차단문을 순차적으로 폐쇄하라.

이 경우 비상방송은 T04가 위치한 복도에 직접 송출하기보다, 차음된 직원 대피 구역과 통제실을 대상으로 전달하는 설정이 적합합니다. 시설 전체의 필수 안전 경보를 일괄 해제하는 지시는 피합니다.

### Q03. 복도에 고립된 직원 구조 [선택 후보]

상황

직원 1명이 B구역의 설비실 안에 고립되었습니다. T04는 설비실 밖 복도에서 구조물 접촉 행동을 반복하고 있습니다. 설비실의 차단문은 정상적으로 잠긴 상태입니다.

질문: 고립 인원에 대한 올바른 지침은 무엇입니까?

A. 동료들이 소리를 내어 개체를 유인하는 사이 복도로 뛰어나온다.

B. 문을 잠근 상태로 외부 접촉을 피하고, 통제실의 안전 경로 확보 지시를 기다린다.

C. 개체가 소리에 반응하는 동안 문을 열고 반대 방향으로 이동한다.

실제 방송 문장 — 정답 B

> B구역 설비실 잔류 인원은 현재 위치를 유지하라. 출입문을 개방하지 말고, 통제실에서 별도 대피 경로를 안내할 때까지 대기하라.

```
    │
    └─ UNSTABLE_1
         ↓
       UNSTABLE_2
         ├─ CONTAINMENT_FAILURE
         └─ BREACH
              ↓
            INCIDENT
              ↓
            BROADCAST
              ↓
            INCIDENT_RESULT
```

이 상태 구조는 콘텐츠 설계안이며, 현재 Godot 프로젝트에 실제로 존재하는 클래스나 상태명을 확인한 것은 아닙니다.

### T04 전용 격리 결과

| 선택     | 결과 ID                 | 후속 처리                 |
| ------ | --------------------- | --------------------- |
| ROOM A | T04_UNSTABLE_STANDARD | 점진적 불안정화, 격리 실패 기록    |
| ROOM B | T04_BREACH_METALLIC   | 구조물 간섭 → 잠금장치 이상 → 탈출 |
| ROOM C | T04_STABLE_LOWSTIM    | 정상 격리 유지              |

중요: 격리 승인 직후 플레이어에게 위 결과 ID나 성공·실패 여부를 보여주지 않습니다. 내부에서만 기록하고, 모니터링과 후속 사고를 통해 결과를 전달합니다.

또한 실험별 Research Log는 플레이어가 해당 실험을 실제로 수행했을 때만 등록되어야 합니다.

### 최종 추천 사항

이번 T04는 다음 세 가지를 특히 유지하는 것이 좋겠습니다.

첫째, 단일 소음 반응이 곧 격리 실패는 아닙니다. 반복적이고 강한 반향 자극이 누적되었을 때 비로소 위험해집니다. 덕분에 실험 결과와 장기 격리 결과를 구별할 수 있습니다.

둘째, 어두운 방이 정답이 아닙니다. ROOM B는 초기 정지 상태 때문에 정답처럼 보일 수 있지만, 실제 위험은 금속 벽면의 반향에 있습니다. T04의 가장 중요한 오답 선택지입니다.

셋째, 탈출 사고에서 갑자기 지능이나 공격성을 높이지 않습니다. 개체는 실험에서 보였던 행동을 그대로 반복하고, 그 결과 연구시설의 구조적 결함을 통해 탈출하게 됩니다.

이 방향이면 T04는 단순한 '두 얼굴을 가진 괴물'이 아니라, 외형을 관찰하고 생리적 특성을 추론해야 올바르게 격리할 수 있는 Case가 됩니다.

현재 설계는 [설정 후보] 단계이며, 사용자 승인 후 개체의 정식 Case 기준으로 고정하면 됩니다.
