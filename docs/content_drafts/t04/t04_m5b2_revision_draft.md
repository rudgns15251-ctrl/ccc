## 0. 목표 플레이 경험

- 현재: CCTV와 격리 설명만 읽으면 "방음과 흡음은 다르다 → ROOM C"가 문장으로 주어집니다. 실험은 확인 절차일 뿐입니다.
- 목표:
  1. CCTV와 과거 소견만 보면 **어두운 ROOM B도 그럴듯해 보입니다**(v0.2의 원래 의도: "어두운 방이 정답이 아니다").
  2. 반향이 핵심이라는 것은 **ECHO 또는 COMBINED 실험의 수치**로 확인하게 합니다.
  3. 그 수치를 격리 후보의 **잔향 시간 값**과 대조해서 C를 고르게 합니다(Papers, Please식 교차 대조).
- 실험을 잘못 골라도 Profile 권고, CCTV, LOWSTIM 결과에 약한 단서가 남습니다. 확신 대신 **위험한 추측**이 되는 정도로 맞춥니다.

## 1. CCTV 관찰문 (`CAM_T04_TEXT_OBSERVATION.observation_text`)

### 바꾸는 이유
- 02:40의 "방음과 흡음은 다른 조건이다"와 마지막 안내 줄이 정답 기준을 직접 말합니다.
- 00:40의 "금속 통로에서 오래 울릴 때 더 오래"는 ECHO 실험 결과와 같은 정보입니다.

### 초안 (사용자 RL_T04_CCTV_01~05의 해금 근거는 모두 유지)
```
[TEMP / DRAFT / NON-CANON] T04 관찰 기록. 화면의 감시 장면은 Master와 표준 격리실을 합성한 임시 이미지이며 실제 감시 영상이 아니다. 열화상은 미제공이다. 판단 근거는 아래 텍스트 관찰이다.

00:00 — 낮고 일정한 조도에서 직립 정지. 팔끝의 미세 탐색은 계속된다. 기준 10분간 구조물 접촉 2회.

00:40 — 일상 점검의 짧은 금속음에 웃는 두부와 상부 팔이 먼저 반응했다. 소리가 멎자 반응이 줄었다. 점검원이 금속 통로를 지나간 구간에서는 반응이 조금 더 길었다. 발소리 때문인지 통로의 울림 때문인지는 이 기록으로 구분되지 않는다.

01:20 — 이동 점검등을 큰 눈의 두부가 따라갔다. 일부 상지만 움직였고 전신 균형은 유지됐다.

02:00 — 점검등 이동과 금속음이 잠시 겹친 순간 두 두부가 다른 방향을 향했고 팔 움직임이 늘었다. 자극이 멎자 자세가 돌아왔다.

02:20 — 실내 조명을 낮춘 구간에서 큰 눈 두부의 회전이 줄고 정지 시간이 길어졌다.

02:40 — 외부 점검 소음이 멎은 뒤에도 접촉이 한 차례 더 이어졌다. 원인은 이 기록만으로 확정되지 않는다.
```

## 2. 격리 후보 설명 (`ContainmentData.description`)

### 원칙
- 평가형 문장("잔향이 오래 남을 수 있다", "구분해 줄이는 구성")을 빼고 **측정값만** 같은 형식으로 나열합니다.
- 값은 신규 [DRAFT]입니다. 실제 음향 공학의 정밀 고증이 아니라 **게임 내 비교값**입니다.

### 초안
| Room | 조도 | 외부 차음 | 내부 잔향 시간 | 마감 | 기류 |
|---|---|---|---|---|---|
| A · 표준 | 중간 · 점검 시 변동 | 보통 (약 35dB 감쇠) | 약 1.1초 | 도장 콘크리트 | 표준 |
| B · 저조도 금속 | 낮음 · 일정 | 보통 (약 35dB 감쇠) | **약 2.4초** | 금속 패널 | 표준 |
| C | 낮음 · 일정 | **강화 (약 55dB 감쇠)** | **약 0.4초** | 흡음 패널 | 표준 |

설명 문자열 예(ROOM B):
```
조도: 낮음·일정 / 외부 차음: 보통(약 35dB 감쇠) / 내부 잔향 시간: 약 2.4초 / 마감: 금속 패널 / 기류: 표준. 임시 비교값: 20°C, 상대습도 45%.
```
A와 C도 같은 형식으로 씁니다.

### [선택] ROOM C 표시명
- 현재 "ROOM C · 저자극 격리실"은 실험 "저자극 환경 반응"과 이름이 겹쳐 힌트가 됩니다.
- **제안:** 세 방 모두 마감 기준으로 이름을 맞춥니다. "ROOM A · 표준 격리실" / "ROOM B · 저조도 금속 격리실"(유지) / "ROOM C · 흡음 패널 격리실".
- `room_id`(`ROOM_T04_LOWSTIM`)는 그대로 둡니다. 이름만 바꾸는 것이고 판정과 저장에는 영향이 없습니다.

### [선택·별도 승인] ROOM B 점검 패널 결함의 사전 노출
- ROOM B 설명 끝에 "출입문 점검 패널 고정 보수 대기."를 추가합니다.
- 설비 결함은 v0.2 [설정 후보]입니다. **승인하지 않으면 넣지 않습니다.**

## 3. 실험 5종 (`description` 일부 + `result_text`)

> 사용자 RL_T04_EXP_* 본문(Research 문장)은 바꾸지 않습니다. 실행 화면의 `result_text`에 **장비 로그 형식의 수치**를 더합니다.
> 실험은 모두 **표준 임시 격리실(내부 잔향 약 1.1초)**에서 실행한다는 v0.2 전제를 그대로 씁니다.

### ECHO — 핵심 실험
- 실행 전 안내 추가 문장: "녹음 잔향 신호는 약 2초 길이의 반사음을 포함한다."
- 결과 초안:
```
[실행 기록 / TEMP]
단발 충격음 — 웃는 두부 회전, 상부 팔 1~2개 반응. 벽 접촉 2회, 접촉 지속 약 5초, 회복 약 40초.
잔향 포함 신호(약 2초) — 같은 최대 음량. 벽·문틀 접촉 9회, 접촉 지속 약 30초, 신호 중단 후 회복 약 4분.
같은 음량에서도 반사음이 길수록 탐색이 오래 남았다. 일회 반응이 곧 격리 실패를 의미하지는 않는다.
```

### LIGHT
```
[실행 기록 / TEMP]
이동광 조사 동안 큰 눈의 두부가 광원을 계속 추적했다. 상지 반응 1개, 구조물 접촉 0회. 광원 중단 후 약 30초 안에 자세가 안정됐다. 전신 협응 붕괴는 관찰되지 않았다.
```

### COMBINED
```
[실행 기록 / TEMP]
이동광과 잔향 음향 중첩 — 두 두부가 서로 다른 방향을 향했다. 네 팔의 접촉 14회, 팔 교차 3회, 몸통 균형 흔들림. 자극 중단 후 회복 약 7분.
단일 자극보다 회복이 크게 늦었다. 이 실험만으로 실제 탈출이나 추가 페널티는 발생하지 않는다.
```

### LOWSTIM
```
[실행 기록 / TEMP]
조도를 낮추고 비필수 음향을 정지한 10분 — 두부 회전이 기준의 약 1/4로 줄고 구조물 접촉 1회.
남은 접촉 1회는 시험실 환기 장치의 작동음 직후에 기록됐다. 벽면 마감(잔향 약 1.1초)은 바꾸지 않았으므로 흡음 성능을 검증한 결과는 아니다.
```

### AIR
```
[실행 기록 / TEMP]
송풍량 증가 시 팔끝과 두부 주변 돌기가 움직이고 상지 1개가 송풍 방향을 향했다. 구조물 접촉 0회, 송풍 복구 직후 정지. 돌기의 감각 기능은 가설이며 이번 관찰로 확정하지 않는다.
```

### 수치가 만드는 비교 축
| 지표 | 기준(CCTV) | LIGHT | AIR | ECHO 단발 | ECHO 잔향 | COMBINED | LOWSTIM |
|---|---|---|---|---|---|---|---|
| 접촉 | 10분 2회 | 0 | 0 | 2 | **9** | **14** | 1 |
| 회복 | — | 30초 | 즉시 | 40초 | **4분** | **7분** | — |

- 플레이어가 스스로 내릴 결론: **"반사음 길이가 핵심이다 → 잔향 2.4초의 B는 위험하다, 0.4초의 C가 맞다."**
- 빛 단독(LIGHT)과 어두움(02:20)의 정보는 B를 지지하는 함정으로 작동합니다.

## 5. 비상방송 선택지 (`BQ_T04_EVACUATION`, `BQ_T04_FACILITY`)

### 원칙
- **option_id와 정답 의미는 유지**합니다(각 문항 `_2`가 자극 감소·차단 후퇴). Research `RL_T04_INCIDENT_04`의 출처 `BQ_T04_FACILITY_2`도 그대로입니다.
- 오답 3개는 각각 **T04 사실 하나만 반쯤 맞힌 절충안**으로 씁니다.
- 지시문 길이를 비슷하게 맞추고, **표시 순서**(options 배열 순서)를 섞어 정답이 항상 3번째에 오지 않게 합니다.
- 문항 질문(`prompt_text`)은 유지합니다.

### Q01 · BQ_T04_EVACUATION — 인접 구역 직원의 이동
| ID | 표시 문구 | 방송 지시문 | 그럴듯한 이유 | 실제 위험(T04 사실) |
|---|---|---|---|---|
| _0 | 손전등을 끄고 벽을 짚으며 이동 | 손전등을 끄고 벽을 짚으며 가장 가까운 출구로 이동하라. | 빛 자극 제거 | 벽면 경로가 **상지 탐색 범위**와 겹치고, 접촉음이 생김 |
| _1 | 무전으로 위치를 짧게 공유하며 이동 | 무전으로 위치를 짧게 공유하며 차단 구역으로 이동하라. | 큰 소리 대신 짧은 교신 | 금속 복도에서 **무전 잡음 반사** |
| _2 ✔ | 발밑만 비추고 말없이 차단 구역으로 | 손전등은 발밑만 비추고 말없이 차단 구역으로 후퇴해 문을 닫아라. | — | 이동광을 대상에 향하지 않음 + 발성 없음 + 차단 |
| _3 | 현재 위치에서 움직이지 말고 대기 | 현재 위치에서 움직이지 말고 통제실의 다음 지시를 기다려라. | 자극 최소화 | 복도에 남으면 **반복 접촉 구간** 안에 머묾 |

- 표시 순서 제안: _3, **_2**, _0, _1 (정답이 2번째).
- 확인 필요: 원래 v0.2의 정답은 "이동광과 발성 **중지**"였습니다. 초안의 "발밑만 비춤"은 이동광을 대상에게 향하지 않는다는 해석입니다. **원문대로 "이동광 중지"를 유지하길 원하면** _2를 "손전등과 발성을 멈추고 거리를 유지하며 차단 구역으로 후퇴해 문을 닫아라."로 씁니다.

### Q02 · BQ_T04_FACILITY — 반향·점멸 복도의 대피 경로
| ID | 표시 문구 | 방송 지시문 | 그럴듯한 이유 | 실제 위험 |
|---|---|---|---|---|
| _0 | 점멸등을 피해 어두운 정비 통로로 | 점멸등 구간을 피해 어두운 정비 통로로 돌아서 이동하라. | 빛 자극 회피 | 정비 통로는 **금속 배관·반향** 구간. ROOM B와 같은 함정 |
| _1 | 경보음이 울리는 동안 빠르게 통과 | 경보음이 울리는 동안 그 소리에 묻혀 빠르게 통과하라. | 발소리를 경보로 가림 | 경보 + 발소리 + 점멸 = **복합 자극** |
| _2 ✔ | 배관 구간을 벗어나 차음 구역에서 대기 | 금속 배관 구간을 벗어나 차음 구역에 들어가 문을 유지하고 다음 지시를 기다려라. | — | 반향 회피 + 차단 유지 |
| _3 | 전원 통과 후 차단문 폐쇄 | 차단문을 열어 둔 채 전원이 통과할 때까지 기다렸다가 닫아라. | 낙오자 방지 | 개방 시간이 길어져 **이동 범위 확대** |

## 6. 사고 결과 16개 (`RESULT_T04_0~15`)

### 구성 방식 — 16개를 직접 쓰지 않고 조합
`RESULT_T04_n`, n = 4 × (Q01 선택) + (Q02 선택). 기존 매핑을 그대로 씁니다.

```
description =
  사고 원인: (현행 유지)
  대응 검토: [정답 수에 따른 문장 1개]
  현장 기록:
   - [Q01 흔적]
   - [Q02 흔적]
  송출한 지시: (Q01 지시문) / (Q02 지시문)

additional_observation = [정답 수 문장] + " 사망·부상 인원은 UNKNOWN이며 0명으로 단정하지 않는다."
staff_deaths / staff_injuries = -1 (UNKNOWN, 변경 없음)
```

### 정답 수에 따른 대응 검토 문장 (3종)
- 2개 정답: "두 지시 모두 자극 감소와 차단 유지에 부합했다. 직접 접촉 노출은 줄었을 것으로 보이나 최종 인명 피해는 확인되지 않았다."
- 1개 정답: "한 지시는 자극 감소에 부합했으나 다른 지시가 위험 구간을 남겼다. 해당 구간 인원의 접촉 노출 여부를 조사 중이다."
- 0개 정답: "두 지시 모두 대상의 탐색 범위나 복합 자극을 키우는 방향이었다. 접근 구역 확대와 피해 가능성을 조사 중이다."
