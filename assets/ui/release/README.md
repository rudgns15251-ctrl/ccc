# Release UI material textures

Project-original textures generated by [`tools/build_release_theme.gd`](../../../tools/build_release_theme.gd) (`-- textures`, fixed seed). No third-party art. Used by `resources/ui/release_instrument_steel_theme.tres`.

| File | Material |
|---|---|
| `steel_panel.png` | Painted steel panel (hammertone noise, raised edge) |
| `steel_background.png` | Darker steel for the screen background |
| `well_panel.png` | Recessed well |
| `crt_panel.png` | CRT glass with bezel and faint scanlines |
| `paper_panel.png` | Report paper |
| `alarm_panel.png` | Alarm band — incidents and transmission only |
| `check_*.png`, `radio_*.png` | Indicator lamps for check boxes |

These are first-pass stand-ins for the art direction. An artist can replace any PNG at the same path (keep 9-slice margins: steel/well 4px, CRT 8px, paper 2px, alarm 3px) or change the theme builder and rerun it.
